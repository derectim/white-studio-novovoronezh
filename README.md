# WHITE STUDIO

Фотостудия в Нововоронеже — статический сайт.

[Открыть сайт](https://derectim.github.io/white-studio-novovoronezh/)

## GitHub Pages

В Settings → Pages выбрать Deploy from a branch, ветку main и /(root).

Файлы index.html, styles.css, app.js и assets публикуются без сборки. Все пути ресурсов относительные и поддерживают адрес вида /название-репозитория/.
